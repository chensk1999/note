# AI

人工智能（Artificial Intelligence，AI）是解决复杂问题的算法。发展过程中出现了许多类技术，比如：

- 机器学习（Machine Learning）：不需人类设计算法就能提高智能的AI
- 深度学习（Deep Learning）：使用多层神经网络的机器学习算法

目前主要的AI实现方式是神经网络，因此AI、机器学习、深度学习、神经网络几乎可以等同。按照网络结构和学习方式可以进一步细分：

- 网络结构：CNN、RNN、Transformer
- 学习方式：无监督、有监督、强化学习（Reinforcement Learning）

# 神经网络

### 结构

神经网络由若干“层”组成，每层可以看作一个函数$f: \mathbb{R}^m \mapsto \mathbb{R}^n$，它接受一个m维向量作为参数，返回一个n维向量。最基本的层是全连接层，它由权重矩阵和激励函数构成

1. **加权求和**：$\mathbf{z = W x + b}$，其中`x`是m维输入向量，`z`是n维输出向量；`W`是$n \times m$维的权值矩阵，`b`是m维偏置向量。`W`和`b`可以任意调节
2. **激励函数**：$\mathbf{a = \phi(z)}$，$\phi$是非线性的激励函数，将它作用于$z$的每个分量得到输出$a$

两步处理得到这一层的函数是$f(\mathbf{x}) = \phi(\mathbf{Wx + b})$。这个函数本身并不复杂，但将好几层连接起来就能得到一个非常复杂的函数。为了方便理解，首先研究这样一个Toy Model：一维输入层、n维全连接隐藏层、一维全连接输出层；隐藏层使用ReLU激活函数$\phi_{ReLU}(v) = max(0, v)$，输出层不使用激活函数

输入为$x$时，隐藏层的输出是$\mathbf{a}(x) = \phi(\mathbf{W_1} x + \mathbf{b_1})$；输出层的输出是$y(x) = \mathbf{W_2 a(x)} + b_2$。假设固定隐藏层的权值和偏置，调整输出层的$\mathbf{W_2}$和$b_2$，这时第二层的作用就是以$\mathbf{a}(x)$作为基函数进行曲线拟合！如果再去调整隐藏层的权值，就是在调整拟合使用的函数系！

这也是神经网络的数学本质——**函数拟合**。将现实问题抽象为数学意义上的函数，就能用神经网络拟合这个函数。大部分现实问题，哪怕是一般人都能轻松解决的问题，经过数学抽象后，都复杂到人脑无法理解、无法想象，但这丝毫不妨碍我们用神经网络拟合这个复杂得不可思议的函数

### 训练

寻找拟合参数的过程称作训练。训练前要先定下目标：是让神经网络输出$y$与“正确”输出$\hat{y}$的差距尽可能小，一般使用**损失函数**$\mathcal{L}$定量描述。最常用的损失函数是平方损失函数$\mathcal{L}(y, \hat{y}) = (y - \hat{y})^2$

例如，训练一个判断图片中有没有人脸的神经网络时，定义输出$y$是“图中有人脸的概率”，即，$y = 0$代表图中不可能有人脸，输出$y = 1$代表图中肯定有人脸。用一张有人脸的图作为参数，希望神经网络输出$\hat{y} = 1$，但实际输出为0.8，那么损失就是$\mathcal{L} = (1 - 0.8)^2 = 0.04$

训练过程通常使用**梯度下降法**。对于给定的输入，输出$y$是网络权值$W$的函数，因此$\mathcal{L}$也可以写作$W$的函数$\mathcal{L}(W)$。采用一阶近似，可得在这一点附近$\mathcal{L}(W+dW) = \mathcal{L}(W) + \frac{\partial \mathcal{L}}{\partial W_i} dW_i$，让W沿着梯度反方向移动时$\mathcal{L}$下降最快，因此将W调整为$W' = W - \eta \cdot \nabla \mathcal{L}$

实践中使用**反向传播算法**（其实就是求导链式法则）计算$\frac{\partial \mathcal{L}}{\partial W}$

理论上来说，梯度下降不保证能找到最优解。沿着梯度寻找最低点时，完全有可能陷进局部极小值，而找不到全局极小值。幸运的是陷入极小值几率很小：极小值点是每个维度一阶导都为0、二阶导都大于0的点，维度较高时几乎没有极小值点。实践中还可以加入一点随机性以避免陷入局部极小值

此外，让模型收敛到极小值时会带来过拟合风险。如果针对某些输入一直梯度下降到最小值，改变输入后这个模型几乎必然不管用


# LLM

大语言模型（Large Language Model，LLM）一般指参数多于10亿的自然语言处理模型。LLM基本采用Transformer架构

## 工作流程

**切分词元与词嵌入**

首先，输入的语句被切分为词元（Token）序列。词元就是LLM的单词表，使用基于频率的传统算法计算得到。每个词元分配一个ID

词嵌入矩阵$W_E$（尺寸为单词表长度 × 词嵌入维度）将每个词元映射为一个向量。对每个词元，使用其ID为索引从$W_E$取出一行，得到该词元对应的向量。嵌入后的向量包含了单词语义，比如近义词之间的夹角通常小于90度、反义词的夹角通常大于90度

然后还要把词的位置也嵌入进去，常用技术是旋转位置编码（Rotary Position Embedding，RoPE），具体做法之后再补充

嵌入后的向量记为$\vec{E}$；后文用”词元“、”嵌入向量“代指这个向量；本笔记默认$\vec{E}$为行向量，但也可能换成列向量并省略转置符号

**注意力**

注意力机制计算不同词元之间的关联，让每个词元融合上下文，从而让模型更好理解上下文。最常用的注意力机制是缩放点积注意力，它用$W_Q, W_K, W_V$三个可调矩阵计算注意力。首先，计算词元$\vec{E_i}$的Q、K、V向量：

- **Query**：$\vec{Q_i} = \vec{E_i} \cdot W_Q$，它代表”我想从上下文获得哪类信息“
- **Key**：$\vec{K_i} = \vec{E_i} \cdot W_K$，它代表”我包含哪类信息“
- **Value**：$\vec{V_i} = \vec{E_i} \cdot \vec{W_V}$，它代表”我对上下文有什么贡献“

$\vec{Q_i}$、$\vec{K_i}$所在线性空间称作”查询空间“，其维度通常比$\vec{E_i}$的维度小得多，$W_Q$和$W_K$的尺寸为词嵌入空间维度 × 查询空间维度；$\vec{V_i}$维度则和$\vec{E_i}$相同，$W_V$是词嵌入空间维度 × 词嵌入空间维度的方阵。词嵌入空间维度通常很高，使用大矩阵的性能很差，因此通常用LoRA的思想把它拆成两个和$W_Q$一样大的矩阵的乘积

从它们的设计目标不难看出，$\vec{Q_i}$和$\vec{K_j}$的点积反映了词元$j$能不能提供词元$i$需要的上下文。据此可以得到$\vec{E_i}$的上下文为
$$
\sum_j softmax(\frac{Q_i \cdot K_j^T}{\sqrt{d_k}}) V_j
$$
其中$d_k$为查询空间维度，用来归一化。写成矩阵形式就是*Attention is All You Need*论文的原始公式：

$$
Attention(Q, K, V) = softmax(\frac{Q K^T}{\sqrt{d_k}}) V
$$

**输出**

1. 将输出向量和解嵌入矩阵$W_U$相乘，得到Logits，对它使用Softmax函数计算下一个词元的概率分布，并随机选择下一个词元
2. 将生成的词元反馈回输入端，重复以上步骤，产生下一个输出。如此重复若干次，输出Token序列即为生成的文本

从工作流程来看，LLM本质上是一个词语接龙机器。只要在输入中包含必要信息，它就能回答特定的问题。背景信息常叫做上下文（Context），具体问题则叫做提示词（Prompt）

## 智能体

智能体（Agent）是用户与LLM之间的中介，能够替LLM执行操作——比如从本地文件、网络、向量数据库获取数据，或者进行文件操作、运行外部程序。例如：

1. 用户询问今天天气如何，Agent将问题转发给LLM，并要求LLM判断是否需要执行操作
2. 第一次生成，LLM回答需要搜索今日天气。通常会要求LLM使用固定格式（如JSON）提出指令，这个技术也叫Function Calling
3. Agent通过网络搜索天气数据，添加到上下文发给LLM
4. 第二次生成，得到最终结果

更先进的智能体还可自行规划执行步骤，分步执行，检查，最终提交完整结果

## MCP

**MCP**（Model Context Protocol）是Anthropic公司主导的开源协议，规定了Agent与外部工具沟通的数据格式。这个设计让Agent主程序和它能调用的功能解耦。工具提供者架设MCP服务器，智能体通过访问MCP服务器调用服务

1. 智能体向服务器请求工具列表，示例：`{"name": "get_weather", "parameters": {"city": "string"}}`
2. 用户询问今天天气，智能体将用户输入和工具列表发给LLM。第一次生成，LLM回答搜索天气的参数
3. 智能体向MCP服务器请求天气，添加到上下文发给LLM
4. 第二次生成，得到最终结果

可见MCP和前文智能体的Function Calling原理相同。它的价值在于定义了调用外部工具的统一接口

## 技能

技能（Skill）是使用自然语言编写的工作流程，将复杂任务流程固化为可复用模板。需要执行相应任务时（可以是关键词触发，也可以用类似MCP的方式调用，取决于智能体的实现方式），将它加载到上下文中

1. 编写SKILL.md。例如，编写一个分析财报的SKILL，包括以下步骤：1. 读取财报文件，提取资产负债表、利润表等数据；2. 计算利率、ROE等指标；3. 以指定格式输出分析结果
2. 用户要求分析财报，智能体识别到关键字后加载SKILL（也可能是首先将用户输入和技能列表发给LLM，由LLM决定要不要调用技能），将SKILL插入到上下文一起发给LLM
3. 首次生成，LLM返回任务步骤：1. 调用工具加载财报文件，将财报内容发给LLM提取数据；2. 将上一步提取的数据再发给LLM，LLM返回指标计算方法，调用数学运算工具计算各项指标；3. 将计算结果发给LLM，返回格式化数据，调用报告生成工具出具报告。注意：这一步其实是将自然语言描述的模糊任务流程翻译为比较精准的工具调用流程。以上步骤中所有“调用”的主语都是智能体
4. 智能体按照LLM的规划进行若干次请求，完成复杂任务

Skill和MCP的区别在于，MCP提供了原子操作接口（如读文件、查数据库、调API）；Skill把原子操作编排为完整工作流程
